First time? Set up the Google Sheet connection
  1. Create a Google Sheet to hold the records.
  2. Open Extensions → Apps Script and paste in the code from google-apps-script.gs (provided alongside this page).
  3. Click Deploy → New deployment → Web app. Set "Who has access" to Anyone, then deploy.
  4. Copy the deployment URL and paste it into the field above. It's only stored in this browser tab.
The script creates a sheet tab, appends one row per scan, and stores the card image in a Google Drive folder linked from the row.

Processing happens in your browser — the image is not sent anywhere except the Google Sheet URL you provide.
Only scan a card with the holder's knowledge and consent.
