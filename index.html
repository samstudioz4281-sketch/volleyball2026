First time? Set up the Google Sheet connection
  1. Create a Google Sheet to hold registrations.
  2. Open Extensions → Apps Script and paste in the code from google-apps-script.gs.
  3. Click Deploy → New deployment → Web app. Set "Who has access" to Anyone, then deploy.
  4. Copy the deployment URL and paste it above. It's kept only in this browser tab for the length of this registration.
